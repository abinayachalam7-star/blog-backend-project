# BlogSphere Backend API (Module 02)

Backend server built with **Node.js** and **Express.js** providing REST APIs for the Blog Application.

## API Endpoints
- `POST /api/register` — Register a new user
- `POST /api/login` — Authenticate user credentials
- `GET /api/blogs` — Fetch all published blog posts
- `POST /api/blogs` — Create a new blog post
- `DELETE /api/blogs/:id` — Delete a blog post by ID

## Setup
1. Run `npm install`
2. Run `npm start`
